# Security Policy

If you discover a security issue in SignalOps, report it privately by email to `contact@siddharthkr.com`.

Please do not open a public issue for vulnerabilities until the problem has been reviewed.

## What To Include

- A short description of the issue
- The affected area of the application
- Steps to reproduce
- Any relevant logs, screenshots, or request examples
- The version, branch, or deployment context if it matters

## Response Expectations

Security reports are reviewed as soon as practical. If the issue is confirmed, the maintainer(s) will coordinate a fix and any follow-up disclosure timeline with the reporter.
